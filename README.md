# Study Planner — лабораторна №9

Гілка `lab-09`: продовження №8 з useReducer, Context API, useEffect, Custom Hooks та localStorage. REST API належить до наступної роботи й у цій гілці відсутній.

## Запуск

Node.js 22.22 або новіший.

```powershell
git clone --branch lab-09 https://github.com/Stas0321/study-planner-labs-08-10.git
cd study-planner-labs-08-10
npm install
npm run dev
```

Перевірка: `npm run lint`, `npm test`, `npm run build`.
