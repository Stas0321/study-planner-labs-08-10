# Перевірка

Автоматизовані браузерні перевірки використовують контрольовані HTTP-відповіді DummyJSON, щоб перевірити UI незалежно від доступності зовнішнього сервісу. Це не підміна джерела даних у застосунку: production-код використовує справжній fetch та VITE_API_URL.

Перевіряються редагування локального завдання, reload/persistence, Undo, остаточне видалення після 5 секунд, API error/retry, пагінація, GET деталей, POST/PATCH/DELETE, відсутність runtime-помилок та горизонтального переповнення на 390 px.

Додаткові ручні сценарії:

1. Порожня/пробільна назва: запис не додається.
2. Зіпсований localStorage: у консолі `localStorage.setItem('study-planner.tasks', '{broken')`, reload. Відновлюються початкові дані.
3. Почніть Undoable Delete та натисніть «Скинути дані»: таймер не повинен видалити відновлений запис.
4. Почніть Undoable Delete й перейдіть на API, зачекайте 5 секунд, поверніться: unmount очистив timer, локальне завдання збережене.
5. Запустіть повторне видалення іншого запису до завершення першого: повідомлення пояснює обмеження одного таймера.
6. Offline + пагінація → error; Online + retry → success. Створення з помилкою зберігає введені поля.
7. Network throttling + швидке перемикання сторінок/деталей: abort без повідомлення звичайної помилки.
8. API POST декілька разів: клієнтські id унікальні. Нові записи не підтримуються серверними PATCH/DELETE; UI пояснює обмеження.
9. LocalStorage недоступне: локальний планувальник залишається працездатним; помилка запису tasks показується повідомленням.

Скриншоти lab09-desktop.png, lab10-desktop.png, lab10-mobile.png створені під час перевірки. Дані API на скриншотах тестові.

## Результат виконаної перевірки

- npm run lint та npm run build: без помилок.
- npm test: 4 тести reducer/валідації пройшли (immutable update, request/undo/confirm, reset, пошкоджені дані).
- Браузерні сценарії з контрольованими відповідями пройшли.
- Окремий live-прогін зі справжнім DummyJSON: успішні GET списку, GET деталей, PATCH completed, POST і DELETE.
- Візуально перевірено desktop і mobile скриншоти.
